# Сайт Primitive

Статический сайт игры [Primitive](https://github.com/boobser1488/Primitive).
Чистый HTML + один CSS-файл, без сборки, без зависимостей, без JavaScript.

## Страницы

| Файл | Что там |
|---|---|
| `index.html` | обзор: что это, возможности, скриншоты, быстрый старт, ссылки |
| `download.html` | релизы, сборка из исходников, Android, что нового в 1.5.0 |
| `guide.html` | гайд игрока: управление, инвентарь, крафт, выживание, настройки |
| `server.html` | свой сервер: настройки, команды, операторы, античит |
| `code.html` | структура кода: крейты, границы слоёв, освещение, мешинг |
| `modding.html` | разработка модов: плагины на Rhai и нативные моды через C ABI |
| `style.css` | тема по фирменному стилю Anthropic: тёмный фон Dark #141413, Poppins/Lora, глиняный оранжевый акцент |
| `img/` | скриншоты из игры |
| `tools/highlight.py` | вписывает подсветку синтаксиса в блоки кода |
| `tools/ping.py` | проверяет доступность серверов и вписывает результат в `server.html` |
| `tools/servers.json` | список проверяемых серверов — правится вручную |

## Посмотреть локально

```bash
python -m http.server 8765
```

Затем открыть <http://localhost:8765>.

## Опубликовать на GitHub Pages

Положить содержимое папки в ветку `gh-pages` (или в `docs/` основной ветки)
и включить Pages в настройках репозитория.

```bash
git init
git add .
git commit -m "Сайт Primitive"
git branch -M gh-pages
git remote add origin https://github.com/boobser1488/Primitive-site.git
git push -u origin gh-pages
```

## Подсветка синтаксиса

Подсветка не подключается скриптом на странице, а лежит в самом HTML:
`tools/highlight.py` расставляет в блоках `<pre><code>` спаны `tok-*`,
а раскрашивает их CSS. Сайт остаётся статикой без JavaScript и без
внешнего CDN.

После правки любого блока кода прогоните заново:

```bash
python tools/highlight.py
```

Скрипт идемпотентен — снимает свою прошлую разметку перед новой, так что
запускать его повторно безопасно. Блоки-справочники (`имя  описание`,
как список команд сервера) помечаются `<pre class="lang-cmdlist">`,
остальные разбираются как команды оболочки.

## Проверка серверов

`tools/ping.py` открывает TCP-соединение к каждому серверу из
`tools/servers.json`, сразу его закрывает и вписывает результат в блок
между метками `<!-- ping:start -->` и `<!-- ping:end -->` в `server.html`.
Заодно кладёт `tools/status.json`.

```bash
python tools/ping.py
```

`--dry-run` — только показать, ничего не писать.

Проверка идёт **на стороне владельца сайта**, а не в браузере
посетителя: у игры нет анонимного запроса статуса (`Ping` в протоколе —
это keepalive внутри сессии), а браузер не умеет в сырые сокеты. Поэтому
на страницах по-прежнему ноль скриптов.

Что делает её безопасной:

- **только соединение** — ни байта не отправляется, слот игрока не занимается;
- **только свой список** — на странице нет поля ввода адреса, иначе сайт стал бы
  сканером портов чужими руками;
- **порты ниже 1024 отклоняются** — проверять `22` игровому сайту незачем;
- **потолки** — 3 секунды на адрес, максимум 20 адресов, не чаще раза в минуту;
- **наружу только опубликованное** — имя, адрес, порт, отвечает или нет, задержка;
- **всё экранируется** перед вставкой в HTML.

Чтобы обновлять статус автоматически, повесьте запуск на cron или
на расписание CI и коммитьте изменившийся `server.html`.

## Что править при новом релизе

- Номер версии: `index.html` и `download.html` (строки с `1.5.0`)
- Раздел «Что нового» в `download.html`
- Имена архивов в таблице `download.html`, если они поменялись
  в `.github/workflows/release.yml`
