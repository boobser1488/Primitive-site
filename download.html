Обе платформы собираются нативно, а не кросс-компиляцией: клиент линкует настоящий графический стек, и архивы делаются из дерева, которое прошло свои тесты, а не просто скомпилировалось.

Что внутри архива

Файлов настроек в архиве нет намеренно. Оба бинарника пишут свои при первом запуске — со всеми значениями по умолчанию. Конфиг с машины разработчика — это как релиз навсегда указывает на 127.0.0.1.

Сборка из исходников

Нужен Rust (стабильный). Больше ничего.

git clone https://github.com/boobser1488/Primitive.git
cd Primitive
cargo run --release -p primitive_client

Обязательно --release. В отладочной сборке построение мира в десять–двадцать раз медленнее, и играть в неё нельзя.

Отдельный сервер:

cargo run --release -p primitive_server

На Linux для линковки клиента нужны заголовки X11:

sudo apt-get install -y libx11-dev

Собрать архив, как это делает релиз

pwsh -File package.ps1 -Zip   # Windows -> dist\primitive_win64.zip
bash package.sh --tar         # Linux   -> dist/primitive_linux64.tar.gz

Android

APK под arm64 собирается скриптом package-android.sh — без Gradle, пятью командами из Android SDK: aapt2 link, d8, zip, zipalign, apksigner.

./package-android.sh   # -> dist/primitive-<версия>-android-arm64.apk

Это не релизный артефакт. APK подписан отладочным ключом — ключом, который есть у всех, — так что Play Store его не примет. Установить можно через adb install или тапом по файлу на устройстве, где разрешены неизвестные источники. Подпись для настоящего релиза требует настоящего хранилища ключей, а оно принадлежит тому, кто игру выпускает.

Проверки

Всё, что можно запустить, чтобы убедиться, что сборка живая:

cargo test --workspace
cargo run -p primitive_server --example verify_broadcast    # сервер должен быть запущен
cargo run -p primitive_client --example gen_placeholder_textures
cargo run --release -p primitive_client -- --export-sounds sounds
cargo build -p flight  && cargo test -p primitive_server --test flight
cargo build -p sandbox && cargo test -p primitive_server --test sandbox
cargo run -p primitive_server --example verify_flight

Что нового в 1.5.0

Мир перестал быть местом, где можно стоять вечно. Появился голод — и всё остальное в этом выпуске существует потому, что он появился: еда, которую надо где-то брать; животные, за которыми надо ходить; огонь, который делает мясо втрое сытнее; погода, которая этот огонь гасит; и металл, ради которого огонь оказалось выгодно держать зажжённым.

  • Голод — тратит не время, а работа: удары, бег, прыжки
  • Что растёт — ягоды, поле, семена и то, что из них едят
  • Костёр — вместо печи: экран, а не строчка в меню
  • Металл — девять инструментов, из которых наконец что-то делают
  • Животные — приходят группами, обходят стены, по-разному отвечают на удар
  • Погода — ясно, дождь, гроза; дождь гасит огонь

Полный список изменений — в CHANGELOG.md.
